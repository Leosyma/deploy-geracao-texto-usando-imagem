# Projeto 4 - Deploy de API Para Geração de Texto a Partir de Imagens com LLM
# Instruções Para Execução do Projeto 

# Abra o terminal ou prompt de comando e navegue até a pasta onde você colocou os arquivos

# Execute o comando abaixo para criar a imagem Docker

docker build -t image-qa:local .

# Execute o comando abaixo para criar o container Docker

docker run -dit --name image-qa-api -p 3000:3000 image-qa:local 

# Visualize os logs para verificar se a API já foi inicializada

docker logs image-qa-api

# Então execute a chamada cliente

python cliente.py
